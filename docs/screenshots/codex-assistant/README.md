# Codex assistant proposal screenshots

These screenshots show the Layerling Codex assistant prototype running locally in English. They are intended as illustrative images for a proposal, not product documentation or a release announcement.

The conversation text is sample content; no CAD request was sent or executed to create it. All visible usage percentages are illustrative sample data, not an account's actual usage. The reset times and detailed quota values in `03-usage-limits.png` are illustrative too. The MCP details view shows a normalized sample editor entry so no other open project's name or editor identifier is exposed. The model names are those returned by the local Codex installation at capture time and may change.

`05-guide-chat-activation-en.png` shows the English Layerling guide chapter with the new editor activation steps.

The additional editor screenshots show the movable chat window, the ChatGPT setting in workspace appearance, and the assistant icon used to open the chat.
